# Redesign the Core Values Section — Seasol Maritime India Pvt. Ltd.

Act as an expert UI/UX designer and front-end animation developer. Inspect my existing website and redesign ONLY the Core Values section to match the existing Mission & Vision section's light, clean, premium corporate design.

IMPORTANT: **Do NOT make this section dark. Do NOT use a dark navy background.** My website uses a white background, dark navy headings, and electric-blue accents. The Core Values section must blend naturally with this theme.

## 1. Inspect the existing design first

Before coding:
- Inspect the current Mission & Vision section and the existing Core Values section.
- Identify the project's framework, CSS files, layout conventions, typography, available icons, and current animation setup.
- Match the existing site's font family, heading styles, blue accents, container width, and spacing.
- Make changes directly in the existing project and preserve the rest of the website.

## 2. Visual direction: premium light corporate UI

Create a single cohesive section titled **“Our Core Values”** that visually complements the white-background Mission & Vision section.

Use this color palette:
- Main background: pure white #FFFFFF or very light grey #F7F9FC.
- Headings: deep corporate navy #092B53.
- Primary accent: electric blue #0866F5.
- Secondary accent: soft blue #EAF2FF.
- Body text: muted slate #58677B.
- Card borders: subtle blue-grey #E0E8F4.
- Shadows: very soft, light grey-blue shadows.

Use navy and blue selectively. The overall appearance must remain bright, spacious, elegant, and professional.

Avoid:
- Dark navy section backgrounds.
- Black or dark cards.
- Heavy blue gradients covering the entire section.
- Excessive glassmorphism, neon glow, or thick borders.
- Oversized icons, unnecessary illustrations, and excessive decorative elements.

## 3. Build one unified section

Create a clean, centered layout with:

Eyebrow:
WHAT GUIDES US

Main heading:
Our Core Values

Subtitle:
“The principles that guide every shipment, strengthen every partnership, and shape the way we serve our clients across CIS markets.”

Add a thin electric-blue accent line beneath the heading or eyebrow.

Keep the content within the site's existing maximum-width container. Use comfortable vertical spacing and ensure the section sits naturally between the surrounding website sections.

Do not create a separate dark panel or duplicate the Mission & Vision content.

## 4. Six animated value cards

Display six consistent cards in a three-column, two-row grid on desktop.

Design each card with:
- White background.
- Rounded corners with a subtle, professional radius.
- A thin light blue-grey border.
- A soft shadow that does not make the card look elevated excessively.
- A light-blue circular icon container with an electric-blue line icon.
- A small, muted two-digit number from 01 to 06.
- A bold navy heading.
- A short, readable description in slate-grey text.
- A small blue accent detail, such as a short underline or subtle left-edge indicator.

All six cards should have consistent padding, alignment, icon sizing, and visual hierarchy.

Use these exact values and descriptions:

**01 — Reliability**
“Dependable handling and consistent follow-through on every cargo movement.”
Icon: Shield or shield-check.

**02 — Integrity**
“Honest, transparent dealings with customers and partners.”
Icon: Scales or check-circle.

**03 — Expertise**
“Practical freight-forwarding knowledge for CIS trade.”
Icon: Compass or award.

**04 — Precision**
“Careful planning, accurate documentation, and execution at every step.”
Icon: Target or crosshair.

**05 — Partnership**
“Long-term relationships built on trust and open communication.”
Icon: Handshake or linked hands.

**06 — Service Excellence**
“Responsive, customer-focused support from enquiry to delivery.”
Icon: Medal, badge-check, or headset.

Use the icon library already installed in the project. Do not use emoji as icons or install a new dependency unnecessarily.

## 5. Smooth, refined animations

The animation should feel professional, premium, and lightweight.

### On scroll
- Fade in the section heading and subtitle with a slight upward movement.
- Reveal the six cards in a smooth staggered sequence.
- Trigger animations when the section enters the viewport.
- Ensure the content remains visible if JavaScript fails.

### On hover
- Move the selected card upward by approximately 3–5 pixels.
- Slightly strengthen its light-blue border and soft shadow.
- Transition the icon from blue to a slightly brighter blue.
- Animate the small accent line smoothly.
- Keep the card's white background intact.
- Avoid aggressive scaling, rotation, flashing, or large movements.

### Background details
- Optionally add a barely visible geometric pattern or soft blue abstract shapes in the background.
- Keep decorative elements extremely subtle and behind the content.
- Use restrained transitions rather than a constantly moving background.

Use CSS transitions and IntersectionObserver unless the project already contains an appropriate animation library such as GSAP. Respect `prefers-reduced-motion`.

## 6. Responsive layout

Desktop:
- Three columns and two rows.
- Balanced card heights and consistent spacing.

Tablet:
- Two columns, with comfortable spacing and readable descriptions.

Mobile:
- A single column by default, or two columns only when the content remains comfortably readable.
- Reduce padding and heading sizes proportionally.
- Prevent horizontal scrolling, overlapping content, and clipped text.
- Keep the animations subtle and ensure the cards remain easy to read and tap.

Use the existing responsive breakpoints whenever possible.

## 7. Integration and quality checks

- Use namespaced CSS classes following the project's existing conventions, for example `.sc-core-values`, `.sc-core-values__grid`, and `.sc-core-values__item`.
- Do not modify global heading, card, section, or icon styles.
- Avoid changing the navbar, hero, Mission & Vision section, footer, or other existing animations.
- Preserve all existing website functionality.
- Check the design on desktop, tablet, and mobile.
- Verify that all six descriptions fit correctly, icons render properly, scroll animations trigger, and no console errors occur.
- Check the final section alongside the Mission & Vision section to ensure that the transition between the two is visually consistent.

Implement the changes in the actual project, then report the files modified and the checks completed.

FINAL DESIGN GOAL: A bright, elegant white-background Core Values section with navy typography, electric-blue accents, subtle light-blue cards, soft shadows, and smooth animations. It must look like a natural continuation of the existing Seasol website, not a separate dark-themed component.

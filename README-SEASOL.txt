SEASOL MARITIME WEBSITE – LOCAL PREVIEW

1. Extract this ZIP.
2. Copy the transend-php folder into your XAMPP htdocs folder, replacing only a separate test copy if prompted.
3. Start Apache in XAMPP.
4. Open http://localhost/transend-php/ in your browser.

The customized Seasol landing page is index.html. Original template pages and assets are retained. The original homepage is backed up as template-original-index.html.

Note: This is a static front-end preview. The enquiry links open the visitor's email application; no database-backed form or shipment tracking system has been connected. Some template imagery is retained as placeholder imagery and should be replaced with approved Seasol images/logo before publishing.

Contact details and office addresses are populated from the supplied Seasol company information. Please verify the spelling of the email address cs2@seasolmartime.com before launch.
